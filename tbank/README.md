# 🛍️ AI Shopping Assistant

Умный ассистент для подбора товаров с использованием LLM. Приложение помогает пользователям находить и выбирать товары с помощью специализированных ассистентов: стилиста, косметолога, нутрициолога и дизайнера интерьера.

## ✨ Особенности

- 🤖 Четыре специализированных ассистента:
  - 👔 Стилист - подбор одежды и создание образов
  - 🧴 Косметолог - подбор средств по уходу за кожей
  - 🥗 Нутрициолог - подбор продуктов питания
  - 🏠 Дизайнер - подбор товаров для интерьера

- 🎯 Умный подбор товаров:
  - Анализ предпочтений пользователя
  - Учет бюджета и требований
  - Рекомендации по сочетанию товаров
  - Поиск изображений товаров

- 💬 Естественное общение:
  - Контекстный диалог
  - Уточняющие вопросы
  - Персонализированные рекомендации

## 🚀 Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- API ключи:
  - OpenAI API
  - Serper API (для поиска изображений)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/shopping-assistant.git
cd shopping-assistant
```

2. Создайте файл `.env` в корневой директории проекта и добавьте необходимые переменные окружения:
```env
# API ключи (обязательные)
OPENAI_API_KEY=your_openai_key
SERPER_API_KEY=your_serper_key

# Настройки приложения (опциональные)
STREAMLIT_SERVER_PORT=8501
STREAMLIT_SERVER_ADDRESS=0.0.0.0
STREAMLIT_THEME_BASE=light
```

3. Запустите приложение с помощью Docker Compose:
```bash
docker-compose up --build
```

4. Откройте браузер и перейдите по адресу:
```
http://localhost:8501
```

## 🔧 Конфигурация

### Переменные окружения

Все конфиденциальные данные и настройки хранятся в файле `.env`, который не включен в репозиторий:

- `OPENAI_API_KEY` - ключ API OpenAI (обязательный)
- `SERPER_API_KEY` - ключ API Serper (обязательный)
- `STREAMLIT_SERVER_PORT` - порт для веб-интерфейса (опциональный)
- `STREAMLIT_SERVER_ADDRESS` - адрес сервера (опциональный)
- `STREAMLIT_THEME_BASE` - тема интерфейса (опциональный)

### Docker

- Порт: 8501
- Автоматический перезапуск при сбоях
- Проверка работоспособности (healthcheck)
- Монтирование локальных файлов
- Передача переменных окружения из `.env`
